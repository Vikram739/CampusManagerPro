# CampusManagerPro

Homework platform for schools. Teachers post assignments to their classes, students upload solutions from a dashboard, and teachers grade them with feedback.

Stack: React 17, Express 4, PostgreSQL 14.

## Local database

```bash
docker compose up -d
```

Starts PostgreSQL 14 on port 5432 with user `campus`, password `campus` and database `campusmanagerpro`.
